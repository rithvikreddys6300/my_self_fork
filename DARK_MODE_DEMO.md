# Dark Mode Demo Page

This is a demo page to showcase the dark mode implementation. It contains various UI elements to test how they adapt to theme changes.

## Usage

1. Use the theme toggle button in the top menu to switch between light and dark modes
2. The toggle uses Sun/Moon icons with smooth transitions
3. Theme preference is persisted in localStorage
4. All UI components adapt to the selected theme

## Components Tested

- Headers and typography
- Buttons (primary, secondary, outline)
- Cards and backgrounds
- Borders and inputs
- Custom design colors
